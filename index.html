For AI agents

Built for the way you build now.

Deploy Boat ships with an MCP server. Your agent gets real tools instead of guessing shell commands, and a guide that tells it how to build apps that deploy cleanly.

deployPublish or update the project and get the live URL, or the error and the end of the build log.
add_serviceGive the app a database, file storage or email, only if it needs one.
get_logsRead the app's output to debug a crash.
set_envSave an API key you gave it, without putting secrets in code.
app_statusIs it running, where, which version.
setup_guideThe rules for apps on Deploy Boat: port, database, storage, secrets.
claude mcp add deployboat -e DEPLOYBOAT_URL=… -e DEPLOYBOAT_TOKEN=… -- npx -y deployboat mcp

The dashboard fills in the details for you: New app → With my AI agent.

FAQ

Questions

Do I need to know Docker or Linux?

No. Deploy Boat uses Docker under the hood and looks after the server for you. You use a dashboard, one command, or your AI agent.

Do I need a domain?

No. Every app gets a free HTTPS address right away. Add your own domain whenever you want; certificates are automatic.

What server do I need?

Ubuntu 22.04 / 24.04 or Debian 12, with at least 1 GB of memory and 5 GB of free disk. Any cheap VPS from Hetzner, DigitalOcean, Vultr, Linode and others works.

Is it really free?

Yes. It's open source under the MIT license. You only pay for your server.

Can I host apps my AI wrote?

That's exactly what it's for. Connect your agent with MCP, say “publish it”, and it handles the rest, including reading logs and fixing failed builds.

Is it production-ready?

It's early. It runs on real servers today, and it's moving fast. Nightly backups with off-server copies are built in, so start there for anything important.

How do I give feedback?

Open an issue on GitHub. Reports of anything confusing are especially welcome.
